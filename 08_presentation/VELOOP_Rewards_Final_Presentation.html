Logical Data Model & Relational ER Architecture (Work Package H)
PostgreSQL 15+ Normalized Schema Safeguarding Financial Integrity

🗄️ Normalized Star-Schema Entities

  • users: Master identity, demographic attributes, and balances.
  • sessions & feature_events: Contiguous visit framing & atomic streaming logs.
  • task_catalog & task_activity: Catalog inventory & execution instances.
  • wallet_transactions: Double-entry financial balance mutations.
  • withdrawals: Payout requests, gateway clearing IDs, and SLAs.
  • referrals: Relational tree mapping referrer to referee.

🛡️ Integrity & Audit Safeguards

  • Financial Protection: ON DELETE RESTRICT on wallet and withdrawal tables prevents destructive cascading deletes.
  • Ledger Immutability: Balances are the materialized sum of signed transactions; zero destructive in-place SQL updates.
  • Tamper-Evident Clawbacks: Self-referencing recursive foreign key on wallet_transactions tracks fraud reversals.
  • Unique Attribution: referrals.referred_user_id is marked UNIQUE.

Data Pipeline & Operating Model (Work Package O)
Lean, Pragmatic, Cost-Effective (< $100/mo) Architecture (Deliverable 16)

🏗️ 7-Stage Operating Architecture

  • Producers: Mobile SDK, Web App, Partner Postbacks.
  • Collection: FastAPI Gateway with Redis 1h sliding cache.
  • Raw Lake: S3/R2 append-only partitioned Parquet.
  • Validation: Pydantic schema validation + DLQ.
  • Transformation: Hourly dbt Core SQL models.
  • Serving Mart: PostgreSQL 15+ analytical read-replica.
  • Presentation: Interactive Streamlit BI Dashboard.

💡 Anti-Bloat Design Principles

  • Avoids expensive distributed enterprise tools before volume warrants it.
  • Supports up to 50,000 DAU and 5,000,000 events/mo at minimal cloud cost.
  • Clear evolutionary roadmap to Kafka / ClickHouse as platform scales to 1M+ DAU.
